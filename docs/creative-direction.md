# Creative contract

所有正式故事使用繁體中文。原稿由作者提供，demo 不代表正式內容。

- 健太郎：開朗、直接、真誠、主動且尊重奈津美，不以刻意撩撥或戲劇化方式表達愛意。
- 奈津美：內向、細膩、溫柔、善於觀察。她已能自然社交，與健太郎自在相處，能主動約會、打趣及表達喜好，不退回早期高中階段的過度拘謹。
- 兩人已交往多年，關係安全、熟悉、互相信任。幻想世界不改寫人格。
- 口語稱呼：奈津美稱「健太郎」，健太郎稱「奈津美」。第三人稱敘述可以使用姓氏。
- 正式序章：奈津美《終於有時間了》與健太郎《比誰都期待的星期六》，覆蓋重疊事件，結束於遊戲約會前一晚。兩份原稿已由 02story 匯入；不代寫後續章節。
- 後續從奈津美到健太郎家開始。穿越方式、重大事件、角色弧線與結局未確認，不自行補完。
- 日常與幻想是同一段關係的延伸。不要先建立戀愛好感度刷分或強制衝突機制。
- 美術由作者提供。現實／幻想造型維持同一視覺風格；本次僅使用 CSS 中性色塊與角色名佔位。

目前預設奈津美篇接健太郎篇，並可在章節目錄自由選擇視角；這是閱讀導覽，不新增劇情分支。後續可依作者偏好調整。

## 2026-11-05 文風修訂優先規則

依使用者最新回饋，第一章目前是可玩但需重整文風及情緒結構的稿件，不視為文學定稿。新增或重寫劇情前先讀 `story-bible/character-card.txt` V2.0，以及 `story-bible/character-research-2026-11-05.md`。

每章先有一條能持續深化的內心線，事件承接並改變人物的注意力、感受或選擇。不能用分離的擁抱、成功、誇讚與看風景事件，加幾句甜蜜反應串成章節。以使用者 CP 拍照片段校準語氣；另兩篇碎片參考感知與內在因果，不移植其創傷基調。此要求是使用者創作方向，不冒稱原作者的寫作公式。

本次僅更新人物設定與寫作依據；第一章新版本先交付可審閱稿，不直接覆蓋目前遊戲正文。後續尚未提供的事件與結局仍不得自行補完。
