# 第一章 V3 修訂備註

狀態：供作者閱讀的新稿，未接入遊戲。V2 保留不變。

這次重分配敘事重心，不只縮短句子：

- 開門、接袋與進屋簡述，擁抱才放慢。近期相處受限的感受在這裡建立，親吻與日常玩笑接著同一份親近，刪去反覆整理頭髮的來回。
- 列車救援縮短操作流程，保留危機、分工、一次未成功的嘗試與互相回應。場景收在奈津美開始想探索城鎮，銜接下一節。
- 麵包保留為短互動，不再為等角色吃完另外寫一段情感結論。點燈讓剛才走過的地方重新出現在她眼前，才進入星鯨。
- 星鯨前半留給世界本身，後半讓奈津美注意到自己在共同活動裡的投入；以兩人的具體回應帶回重逢時的期待，不在此堆疊多個獨立領悟。
- 白光結尾從遊戲外的風、聲音與物件切入，不延伸穿越後情節。
