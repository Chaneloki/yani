# 02｜章節大綱：從普通星期六到真正的明天

> **定位**：本文是故事施工藍圖，不是已完成小說。**【確立】** 僅指與作者對話中已確認的事實；章名、第 1 章以後的細節、人物名與場景屬 **【暫定】**。正篇不得由 Codex 自行填補未定設定。世界規則參考 [`01_worldbuilding.md`](01_worldbuilding.md)；專有名詞見 [`03_glossary.md`](03_glossary.md)。

## A. 整體篇章設計

**【確立】** 「王道奇幻 RPG ＋ 世界異常謎團」主線，並以 NPC 命運、生活與地區故事組成支線。男女主角是多年交往、互相信任的伴侶，不需要重新經歷初戀試探。愛情日常一直存在，但主線的壓力來自世界的規則、選擇、物資、時間和其他人的人生。

**【暫定】** 章節數量：雙視角序章＋11 章主線＋終章。第一輪的故事進入點接近 90 日輪迴尾端，讓第一個重置於第 5 章發生；隨後進入下一輪並嘗試在第 90 日之前完成修復。這是**敘事節奏提案，不是已確認的固定日曆**。

### 三段情緒節奏

1. **戀愛日常與世界初遇（序章至第 3 章）**：生活感、約會、笑點、雙人探索、熟悉 NPC，世界值得喜歡。
2. **重置與尋找出路（第 4 至第 9 章）**：線索由局部異常變成完整證據；重新幫助被忘記的朋友，修復三座星錨。
3. **反轉、行動與告別（第 10 章至終章）**：重新理解「魔王」，面對守鐘人的困境，讓 NPC 真正擁有明天。

## B. 已完成序章：固定事實與雙視角分工【確立】

### 序章 A｜《終於有時間了》｜西視角

- 西大學最後一科期末考結束，終於可以擺脫報告與考試壓力。
- 健太郎中午從自動車專門學校實習工場傳來拆開車頭的照片；照片有點歪，甚至拍入鞋尖。他記得這是西最後一科考試。
- 兩人近來仍有見面、吃飯和散步，只是每次相處時間短，未能好好約會。
- 同學在咖啡店介紹熱門雙人合作幻想 RPG，可在同一台主機用兩支控制器遊玩。
- 西回家研究遊戲，看到魔女意外炸飛勇者的搞笑片段，轉發給健太郎。
- 西自然地主動邀請星期六到健太郎家打遊戲，表達想好好約會；健太郎高興答應、即刻購買。
- 健太郎準備兩支控制器及大量零食；兩人選擇勇者與魔女。
- 西提前挑好衣服，約好約十一時到達，兩人對明天充滿期待。

### 序章 B｜《比誰都期待的星期六》｜山田視角

- 同一條時間線由健太郎的實習、拍照、傳訊、等待奈津美考完試寫起。
- 他也一直想和奈津美多相處，理解她重視課業，沒有令她因見面而感到壓力。
- 他原本構思星期六一起出門，收到奈津美提議後，真心樂意轉成宅家約會。
- 買遊戲、下載、檢查控制器、購買零食、安排第二個鬧鐘，都自然反映其行動力與期待。
- 「我保護妳」和「魔女大人／勇者」的玩笑，是多年情侶的自然親密，而非單向照顧。

**一致性限制**：雙視角涉及相同訊息、同一購買動作、同一個星期六，日期與措辭須對得上。遊戲正式名稱、兩人家中具體格局及穿越觸發方式尚未在序章定案；後續不可倒填改寫已發生的事。故事實稿以使用者提供的原文為準，以上僅為索引摘要。

## C. 主線逐章施工大綱【暫定】

### 第 1 章｜普通的星期六

**時地**：星期六上午，健太郎家。**視角**：可以西為主要視角，偶有山田的短段補充，但避免重複整章內容。

**開場**：奈津美準時到達，帶來答應購買的食物；健太郎有些得意地展示已準備好的控制器與零食。彼此自在，日常的玩笑和小動作比誇張的臉紅更重要。

**故事節拍**：一起收拾好桌面 → 閒聊最近生活 → 決定先玩還是先吃／調整座位 → 啟動遊戲 → 介紹世界預言、勇者與魔女 → 選職業、看第一段動畫 → 在操作上發生一些好笑的小失誤 → 發現一則不起眼的異常提示（不能過早揭露星鐘）。

**人物場景**：健太郎興奮但懂得配合奈津美；奈津美也會主動研究玩法、吐槽、幫忙。兩人不是第一次單獨待在家裡，互動不應彆扭。

**玩家互動**：觀賞同一段故事但可選「先看職業介紹／先試操作」等流程分支，最後回到同一主線。不可讓玩家改成完全不同職業，因為兩位角色的外觀與劇情已設定為勇者／魔女。

**章末鉤子**：出現無法解釋的光／聲／畫面切換，**觸發方式待定**。盡量先讓玩家享受完整的宅家約會，穿越才有反差。

**素材方向**：現實立繪 ×2、室內背景、遊戲封面與登入畫面、首次二人 CG（可延後）。

### 第 2 章｜無法登出的世界

**時地**：艾斯特拉的野外、新手區、初始小鎮。**暫定輪迴時間**：本輪約第 75 日。

**開場**：兩人發現自己真正身處畫面中的世界，外貌變成勇者與長髮魔女；先確認對方安全，再試探衣物、道具、身體感覺及能否登出。

**故事節拍**：確認並非尋常遊戲畫面 → 找不到熟悉的退出方式 → 初次實地施法與拔劍 → 面對一個能力範圍內的小危險 → 共同尋找安全落腳點 → 首次與 NPC 正常交流 → 遇到公會／旅店。

**人物場景**：兩人可以驚訝、好奇與輕微不安，但不因處境突然互相指責或失去熟悉感。健太郎欣賞奈津美的魔法，奈津美也會覺得勇者裝的他有趣。

**玩家互動**：引導式探索與基礎魔法／劍術示範；選項影響先試哪件事或額外台詞，不建立實裝完整戰鬥系統為前提。

**章末鉤子**：地圖與宣傳中的版本出現細小差別；小鎮居民把兩人當作傳說中的旅人。

**必須守住**：受傷、HP、登出與系統提示尚未定義完整規則，先寫保守，不靠 UI 任意解救。

### 第 3 章｜鐵砧上的約定

**時地**：初始小鎮、工坊、附近礦道。

**開場**：公會或居民介紹一名對手藝充滿熱忱、卻不斷失敗的年輕鐵匠學徒。健太郎因學校實習背景對工具和做法特別感興趣。

**故事節拍**：建立交情 → 幫忙尋找材料、檢查工具或完成小委託 → 健太郎提出具體觀察，當地工匠補足真正的技術 → 奈津美以法術或細心觀察提供重要協助 → 成功做出學徒第一件滿意的作品 → 約定日後再見。

**情感錨點**：學徒親口說自己將來的目標，並送兩人一件**不必過分強力**的小紀念物。這場溫暖的成就，將於第 5 章被抹去。

**支線**：工坊附近居民、修理小玩具／生活器物等純日常委託，讓小鎮顯得真實。

**世界線索**：物料記錄中可藏一個難察覺的過期日期；此時不要明確告知輪迴。

**玩家互動**：可選幫學徒的方式與先後順序，改變對話／額外技術觀察，不讓玩家一個錯誤選項徹底毀掉 NPC 命運。

### 第 4 章｜不存在的日期

**時地**：魔法小店、古舊鐘錶舖、書庫。

**開場**：奈津美被一位魔女學徒邀請研究藥水。配方中的植物名稱與當地現存記錄對不上。

**故事節拍**：歡樂的藥水實驗（可有無害的小失敗） → 發現頁面上記載了不存在於當前曆法的日期 → 鐘錶匠說出奇怪的「昨天」 → 兩條獨立線索互相印證 → 兩人決定保留筆記，繼續調查。

**人物場景**：奈津美可以自主問問題、與學徒自然合作；健太郎提供不同角度的觀察與鼓勵，不需要負責替她社交。

**支線**：幫忙整理配方、送藥、小小研究成果；在世界令人喜愛的前提下增加違和感。

**玩家互動**：線索比對與對話選擇；所有通關必需線索必須有兜底路徑，不依賴玩家猜中唯一一個答案。

**章末鉤子**：城鎮外天空出現暮蝕早期徵兆／某個天文裝置突然逆行。**不得在此直接講出全部答案**。

### 第 5 章｜被忘記的早晨

**時地**：輪迴終點與重啟後的初始小鎮。**暫定**：本輪第 90 日 → 下一輪第 1 日。

**開場**：暮蝕臨界、空間／鐘聲出現異象，主角無法阻止第一次重置。場景與時間回到了熟悉的起點。

**故事節拍**：確認自己記得一切 → 找到先前的店鋪與工坊 → 和鐵匠學徒打招呼卻被當作陌生人 → 兩人共同完成的作品不存在 → 證據令人相信世界的時間被重置 → 從失落轉向想找原因。

**重要描寫**：健太郎先是真心想再見朋友，得知對方不認識自己時才感到衝擊；奈津美也會受到影響，但能自然與 NPC 再說話、研究周圍的差異。二人可互相扶持，而不需要因意見不合吵架。

**玩家互動**：回訪熟悉場景，對比「前／後」對話及物件；關鍵感受應透過具體細節而非大段機制說明完成。

**章末鉤子**：有一個物件／人似乎留下殘響，指向「星鐘」。

**製作注意**：從這章起必須考慮世界狀態與 NPC 記憶：`cycle`、`worldDay`、`npcAwareness`、`clueFlags` 的敘事抽象足夠，不必立刻做複雜模擬器。

### 第 6 章｜記得昨天的人

**時地**：鐘錶舖、舊檔案、王都方向的旅途。**暫定**：新輪第 1–6 日。

**開場**：兩人循殘響找鐘錶匠／留下異常記錄的人，整理上輪的已知事實。

**故事節拍**：重新取得信任 → 發現有些物件不完全受時間重置影響 → 確認九十日循環與能量耗損的初步證據 → 得到三座星錨的古代傳說及所在地線索 → 作出「除了回家，也想讓朋友迎接明天」的自發決定。

**關係描寫**：這不是兩人信任彼此的考試，而是兩人如何將長年默契用在陌生問題上。

**玩家互動**：線索整理、小地圖選擇，三座星錨可在形式上自由瀏覽資料，但首次製作建議固定**鑄火 → 森之 → 潮汐**的主線次序以控制連續性。

**章末鉤子**：星鐘能量消耗的事實，證明下一輪不保證一定存在。

### 第 7 章｜鑄火之章

**時地**：工坊、礦區與第一座星錨。**暫定**：新輪第 7–25 日。

**開場**：舊工坊難題以不同方式再次出現，兩人得用新輪現存的資訊重新和學徒合作。

**故事節拍**：找材料／辨識故障 → 工匠與健太郎合作試驗 → 奈津美用魔法維持安全及提供測量幫助 → 面對裝置啟動風險 → 修復第一錨 → 學徒重新以自己的努力完成作品。

**情感呼應**：不是替 NPC 取回上一輪所有記憶，而是守住讓他繼續成長的條件。

**玩家互動**：安全的機關謎題、材料路線、可選工坊支線。錯誤操作可導致額外補救，不必以任意死亡懲罰。

**章末鉤子**：第一錨啟動後，出現其他兩錨失聯的明確信號。

### 第 8 章｜森林不願遺忘

**時地**：魔法研究區、森林、第二座星錨。**暫定**：新輪第 26–45 日。

**開場**：魔女學徒再次登場，某份配方在新輪又出現「不存在的植物」，可和早前的異常互證。

**故事節拍**：進入有魔力流動問題的森林 → 研究法術、藥劑與植物 → 當地居民的小型生活問題與主線互相交織 → 奈津美提出實驗方案，健太郎在探索及危機時發揮作用 → 修復第二錨。

**情感描寫**：奈津美是有能力參與研究的夥伴，不是等待勇者稱讚的魔法少女；山田喜歡她展現的新一面，兩人可以有幽默的魔法失誤。

**玩家互動**：選路、植物辨認、非戰鬥魔法運用；支線不應全部變得悲壯。

**章末鉤子**：魔力恢復讓遠方一段無法辨識的星圖顯現。

### 第 9 章｜潮汐的星圖

**時地**：港口、燈塔、潮汐星錨。**暫定**：新輪第 46–65 日。

**開場**：港口某些紀錄的日期與潮汐圖不符，鐘錶匠的資料成為關鍵。

**故事節拍**：把城鎮、森林及港口三組證據對齊 → 辨認星鏡與星鐘的不同用途 → 為潮汐星錨完成同步 → 確認「魔王討伐」其實可能觸發新一次災難 → 獲知北方封印守護者的存在。

**NPC 支線**：一直未能送出的信／等待歸來的人，在這裏開始有清楚的收束方向。

**玩家互動**：多線索的星圖謎題，允許玩家查閱筆記和 NPC 的協助；三座星錨修復紀錄應可檢索。

**章末鉤子**：遊戲主線的最終任務提示，與已掌握的歷史證據明顯互相衝突。

### 第 10 章｜終夜之城的守門人

**時地**：北方終夜之城、封印周圍。**暫定**：新輪第 66–78 日。

**開場**：兩人決定不盲從「擊敗魔王」指示，先調查封印真正的運作方式。

**故事節拍**：穿過高危地區 → 與受侵蝕的守門人交鋒或周旋 → 發現他一直擋住裂縫 → 不否認他因侵蝕而造成的傷害 → 找出一個既能保護居民、又不會直接毀掉封印的替代方案 → 守鐘人的立場浮現。

**關係描寫**：健太郎不是無腦衝上去殺敵；奈津美不是永遠負責勸他冷靜。讓兩人以不同優勢共同提出風險可控的策略。

**玩家互動**：戰鬥與證據蒐集並重；若有分支，應影響協助方案、代價與 NPC 後果，而非強迫角色違反既有人格。

**章末鉤子**：星鐘的最後一次重置倒數開始；若失敗，未必還有足夠能源恢復。

### 第 11 章｜逆刻星鐘

**時地**：星鐘核心／封印結構。**暫定**：新輪第 79–90 日。

**開場**：守鐘人拒絕貿然停鐘，因他曾見過真正的毀滅；兩人帶著三座星錨的修復資料與 NPC 的實際協助來到核心。

**故事節拍**：揭露當年不得不啟動星鐘的原因 → 說明繼續重置的代價 → 檢查三錨同步是否可行 → 協調守門人對裂縫的最後防護 → 讓 NPC 的專長真正參與解法 → 進行有明確失敗風險的修復 → 選擇停止輪迴。

**高潮原則**：情感是決心，**不是解題的魔法替身**；必須以先前建立的技術、線索、道具、夥伴與犧牲風險完成。可以有緊張戰鬥與危機，但不能突然出現從未預告的萬能能力。

**玩家互動**：最終多階段劇情／謎題，部分支線可帶來額外協助與尾聲變化。作者尚未決定多結局架構，暫不寫出必定存在的壞結局。

**章末鉤子**：星鐘停下；隔天的太陽是否會升起？

### 終章｜第九十一日

**時地**：第一次真正的第 91 日、之後的現實世界。

**開場**：世界迎來從未經歷過的下一日。鐘錶匠的鐘繼續走；學徒可以真正完成下一件作品；郵差有機會送出那封信。

**故事節拍**：走訪少數熟悉的 NPC，讓他們的生活繼續而非停格在對主角道謝 → 尋得可行返鄉路徑（具體機制待定） → 健太郎與奈津美告別 → 回到最初那個星期六的房間／控制器／零食 → 二人以自然又略帶難以置信的方式消化經歷。

**情感收束**：不以「我們學會相信彼此」作主題，因為他們本已信任；重點在「共同見證了許多人的明天」，且回家後仍然是原本那對會彼此逗笑的情侶。

**後日談選項**：NPC 的日常後續、地區小 CG、重返那款遊戲時的感受。是否能再聯絡異世界、現實流逝時間均【待定】。

## D. 支線任務結構及主線連動

| 支線代碼 | NPC 構想 | 首次登場 | 主要情緒 | 可帶來的變化 | 必需？ |
|---|---|---|---|---|---|
| SQ-FORGE | 鐵匠學徒 | 第 3 章 | 成長與被忘記的友情 | 修復工藝／星錨額外支援 | 主線會認識；額外委託可選 |

| SQ-CLOCK | 鐘錶匠 | 第 4–6 章 | 記憶、證據與時間 | 重置證據、潮汐同步幫助 | 主線關鍵 |
| SQ-LETTER | 郵差與收信人 | 第 4 或 9 章 | 等不到的明天 | 終章情感收束、額外 CG | 可選 |
| SQ-TOWN | 城鎮日常居民 | 第 2–4 章及返訪 | 熱鬧、輕鬆、世界生命力 | 小道具、笑點、背景變化 | 可選 |

**重置後支線狀態**：先區分「玩家跨輪記得什麼」與「NPC 當輪認為發生了什麼」。避免支線直接沿用前一輪的 NPC 信任值而自相矛盾。已知道的線索可幫主角重新取得信任，但不應令 NPC 平白認得兩人。

## E. 為互動文字遊戲設計的選擇框架

- **風味型選擇**：不同俏皮對話、飯菜、先看哪份介紹；不改變兩人的核心人設。
- **順序型選擇**：先探索工坊、先訪問鐘錶匠、先研究配方；改變資訊呈現次序，最後回到必要主線。
- **支線型選擇**：接受或延後幫助某個 NPC；帶來角色互動、道具、CG、後日談差異。
- **解謎型選擇**：由收集證據推論規則，允許錯誤後重試及求助，避免一個答案堵死故事。
- **關鍵抉擇**：處理守門人、是否冒險停止星鐘；選項必須有充分資訊與可理解代價。結局數目待作者批准。

**不適合的機制**：以「愛情好感度」懲罰玩家令情侶忽然冷漠、強迫奈津美在社交場合失能、為戲劇效果讓健太郎經常無視奈津美意願。

## F. 製作順序與驗收點（供 Codex）

1. 先把雙視角序章原稿以獨立資料檔匯入，保留原文，建立兩個觀點的切換及共用時間點。
2. 建立第 1–2 章小型可玩原型：對話、選項、場景背景、立繪版本切換、事件旗標、回顧及存讀檔。
3. 第 3–5 章證明「NPC 第一次見面 → 建立關係 → 重置 → NPC 忘記、主角記得」這條敘事狀態鏈能運作。
4. 後續章節依星錨逐一增加系統，而非一次建完戰鬥、背包、工藝及時間模擬。
5. 每完成一章核對：人物語氣、雙視角時間、NPC 的當輪記憶、已取得的線索、輪迴時間及可用技能。

**素材規劃（初步）**：現實山田、現實西、勇者山田、魔女西四套立繪；各自不同表情；家中、學校／街道、小鎮、工坊、魔法研究室、森林、港口、王都、終夜之城、星鐘核心等背景；日常與冒險 CG。正式素材清單可於分鏡完成後獨立整理。

## G. 必須由作者再拍板的創作問題

1. 穿越當晚到底發生甚麼？光效、控制器、星鏡之間的具體觸發如何呈現？
2. 世界中的遊戲 UI 是真實可見、只有主角可見，還是隨時間逐漸消失？
3. 完整九十日的日期、地區旅行時間和任務時長如何安排？
4. 記憶／道具／裝備跨輪的處置；NPC 與來者在重置瞬間所處位置的規則。
5. 受傷、死亡與治療的實際代價，避免輕率設定。
6. 守鐘人、守門人正式人格與過去；是否真有能與之對話的轉機？
7. 最終是單一主結局＋支線尾聲變化，還是存在有因果的多結局？
8. 現實世界經過多少時間，以及返鄉後是否仍可接觸艾斯特拉？

> **主線綱領**：最初只是「星期六一起玩遊戲」，後來是「找到回家的方法」，最後變成「讓認識的人有真正的明天」。山田與西的關係本身始終穩固；變化的是世界及兩人參與世界的方式。
