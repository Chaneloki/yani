# 02｜章節大綱：從普通星期六到真正的明天

> **定位**：本文是故事施工藍圖，不是已完成小說。**【確立】** 僅指與作者對話中已確認的事實；已有序章、第 1–2 章正文以作者稿件為準；後續章號、章名及未寫細節仍為 **【暫定】**。本次採納的線索順序與歸途主線不等於已批准新增小說正文。正篇不得由 Codex 自行填補未定設定。世界規則參考 [`01_worldbuilding.md`](01_worldbuilding.md)；專有名詞見 [`03_glossary.md`](03_glossary.md)。

## A. 整體篇章設計

**【確立】** 「王道奇幻 RPG ＋ 世界異常謎團」主線，並以 NPC 命運、生活與地區故事組成支線。男女主角是多年交往、互相信任的伴侶，不需要重新經歷初戀試探。愛情日常一直存在，但主線的壓力來自世界的規則、選擇、物資、時間和其他人的人生。

**【暫定】** 章節數量：雙視角序章＋11 章主線＋終章。第一輪的故事進入點接近 90 日輪迴尾端，讓第一個重置於第 5 章發生；隨後進入下一輪並嘗試在第 90 日之前完成修復。這是**敘事節奏提案，不是已確認的固定日曆**。

**【確立｜本次主線方向】** 尋找古石門 → 沿途取得五段局部線索 → 親自確認石門不能返家 → 比對既有資料，轉查舊觀星台 → 讀到界外星鏡記錄並確定下一調查方向 → 首次親歷重置 → 同時追查星鏡與時間異常 → 確認印記但通道不穩 → 修復世界 → 第九十一日後校準星鏡返家。回家一直是主角的具體目標，不因中途得知世界危機而消失。

**章號與時間限制**：下列維持 11 章工作骨架，並非要求把星燈城、石門與觀星台擠成固定篇幅；正式分鏡可拆章。保留本輪將近尾聲的工作方案，但「抵達後生活日數」與「輪迴第幾日」須另行對照，不能把現有踩地圖日數直接套成九十日曆法。

### 三段情緒節奏

1. **戀愛日常與世界初遇（序章至第 3 章）**：生活感、約會、笑點、雙人探索、熟悉 NPC，世界值得喜歡。
2. **歸途誤判、重置與雙重追查（第 4 至第 9 章）**：石門失敗讓前段線索第一次串連；觀星台帶來星鏡方向後才重置，第二輪的返家與修復逐漸交會。
3. **反轉、行動與告別（第 10 章至終章）**：重新理解「魔王」，面對守鐘人的困境，讓 NPC 真正擁有明天。

## B. 已完成序章：固定事實與雙視角分工【確立】

### 序章 A｜《終於有時間了》｜西視角

- 西大學最後一科期末考結束，終於可以擺脫報告與考試壓力。
- 健太郎中午從自動車專門學校實習工場傳來拆開車頭的照片；照片有點歪，甚至拍入鞋尖。他記得這是西最後一科考試。
- 兩人近來仍有見面、吃飯和散步，只是每次相處時間短，未能好好約會。
- 同學在咖啡店介紹熱門雙人合作幻想 RPG，可在同一台主機用兩支控制器遊玩。
- 西回家研究遊戲，看到魔女意外炸飛勇者的搞笑片段，轉發給健太郎。
- 西自然地主動邀請星期六到健太郎家打遊戲，表達想好好約會；健太郎高興答應、即刻購買。
- 健太郎準備兩支控制器及大量零食；兩人選擇勇者與魔女。
- 西提前挑好衣服，約好約十一時到達，兩人對明天充滿期待。

### 序章 B｜《比誰都期待的星期六》｜山田視角

- 同一條時間線由健太郎的實習、拍照、傳訊、等待奈津美考完試寫起。
- 他也一直想和奈津美多相處，理解她重視課業，沒有令她因見面而感到壓力。
- 他原本構思星期六一起出門，收到奈津美提議後，真心樂意轉成宅家約會。
- 買遊戲、下載、檢查控制器、購買零食、確認翌日安排，都自然反映其行動力與期待。
- 「我保護妳」和「魔女大人／勇者」的玩笑，是多年情侶的自然親密，而非單向照顧。

**一致性限制**：雙視角涉及相同訊息、同一購買動作、同一個星期六，日期與措辭須對得上。遊戲名稱與室內細節以後續作者正文為準；序章不預先揭露穿越真因。後續不可倒填改寫已發生的事。故事實稿以使用者提供的原文為準，以上僅為索引摘要。

## C. 主線逐章施工大綱【暫定】

### 第 1 章｜普通的星期六【已有作者正文】

**索引**：見到你了 → 前往星燈之城 → 星燈祭 → 冒險才剛開始／山谷草坡。沿用目前作者正文，不以早期施工草案取代。

兩人的重逢與熟悉相處，逐步帶到真正投入合作遊戲、列車救援、星燈之夜，再到古石門場景與白光。穿越後先確認彼此，保留對外貌、觸感與列車的具體反應。不能補回山田睡過頭遲到的情節，也不在遊戲中重複長篇描述玩家剛完成的操作。

**作者層因果**：遊戲石門場景與星鏡共鳴同時發生，真正跨界原因是星鏡；角色與玩家此時只看見事故，不知道真因。不能在這章明說星鏡、印記、輪迴或命定勇者。

### 第 2 章｜離家很遠的地方【已有作者正文】

**索引**：山坡下的路 → 埃斯特拉 → 紙上的路。兩人以「回到那道石門，或許能照原路回去」作合理假說；村中問路、旅舍落腳、整理地圖與明日安排，讓回家從抽象願望變成可開始的調查。

**人物重點**：陌生環境與兩人熟悉相處並存。山田主動觀察、交談、處理眼前需要；西自然交流、記下線索，也會留意與逗趣他的反應。不要把他們寫成只會驚叫的勇者與被動的魔女。

**章後村莊生活【已採納玩法方向】**：解鎖踩地圖、時段、住宿、工作、背包與成長；任務統一在廣場接取。必做《第一份工錢》建立流程與人物關係，再依已定村莊方案完成北路探索、取得奧倫確認的商道／同行資料，準備旅費與物資後出發。艾梅及角色專屬支線不是離村門檻。這段可依玩家安排展開，不把所有支線硬塞成第 3 章的固定正文。

### 第 3 章｜山間驛站【工作名】

**時地與眼前目標**：離開埃斯特拉村，沿奧倫介紹的商道尋找星燈之城與古石門。實際交通日數待排，不能直接固定成本輪第七十五日等日期。

**故事節拍**：將住宿、接委託與問路所得化為出發準備 → 沿途接觸商旅與各自生活 → 在山間驛站為確認道路查舊商隊路線圖 → 發現古石門標為「觀測地點」而非出口 → 暫推測可能要配合星位啟動 → 途中由古老星象儀器或旅人記錄接觸無法解釋的星光／時間矛盾。

**五段線索的前半**：村莊提供傳聞與商道；驛站提供必要舊圖；途中提供可被合理誤解的異常。每段都出於旅行、住宿、工作或查路的需要，不讓 NPC 接力講設定。儀器與記錄的具體事件尚待作者寫作，不自行補成新人物支線。

**人物與推論**：西整理筆記，山田同樣記得實物、地圖與他人的說法。兩人把「需要星位啟動」當工作假說，不確證門可跨界；觀察、記錄與行動不限於固定一人。

**主線兜底**：即使未遇艾梅，驛站舊圖亦能帶出完整調查方向；若有她的傳聞，增加提早認出鏡面石門與專屬對話。

**章末方向**：前往星燈之城查史與尋門，已有一個可回頭重讀的詞——「觀測」。

### 第 4 章｜觀測地點【工作名】

**時地**：星燈之城、城外古石門，再指向城內舊觀星台。城中人物姓名與具體史料載體待定。

**故事節拍**：為查門的用途接觸城市歷史與星象研究相關人物 → 得知古人曾觀測「天空以外的地方」 → 帶著原有假說到門前，確認圓鏡、星形刻紋與兩個圓形平台／啟動位置吻合遊戲 → 兩人親自嘗試卻不能跨界 → 留出失望與彼此相伴的時間 → 重新攤開沿途圖記，修正用途假說 → 找到舊觀星台這個具體下一站。

**推理轉折必備**：

- 西想起驛站寫的是「觀測地點」，而非「入口」，再取出城史的觀星台記錄。
- 山田對照實物與地圖，認出同款星形刻紋；對站位與標記的記憶亦有作用。
- 刻紋更像方位與星象測量用途，早前「看星位才能開門」的推測因此被重新理解。
- 得到的是可查證的新方向，不是已經證明星鏡可送他們回家；也不能由突然出現的學者一次講完答案。

**玩家互動**：實際檢查石門、調查啟動位置、比對先前取得的記錄；必要證據有主線保障，筆記可重看，錯誤推論可重新整理。玩家應感到先前認識的人與看過的資料真的有用。

**情感主線**：失去原先相信的歸途，仍能從共同經歷找出下一步；希望來自證據與兩人一起做的事，不用突然出現的新使命蓋過失望。

### 第 5 章｜被忘記的早晨【工作名；首次重置的敘事位置確立】

**開場／重置前**：兩人在舊觀星台找到殘缺古研究記錄，首次讀到「界外星鏡」與向另一世界傳訊的用途。他們不立即全盤相信，但遊戲與艾斯特拉相似第一次有了可能解釋。裝置本體不必在觀星台，具體所在地與記錄指向的下一調查地點均 `TBD`。

**重置前節拍**：檢視記錄真偽與缺頁 → 開始追查裝置 → 鐘聲與時間不符、星象記錄矛盾、天空變化逐漸頻繁 → 兩人終於確定下一調查目標 → 星鐘第一次在玩家面前啟動，世界回到原初日。**不可退回「一到石門失敗便立刻輪迴」的舊順序。**

**角色知識上限**：此刻只知星鏡可能曾傳訊界外，尚未知印記、穩定回程條件、九十日長度、星鐘用途與有限能源。後期作者真相不得提前當成主角推論。

**重置後節拍**：兩人確認都記得 → 重訪熟悉地方、莉妲／多恩等人物卻不再記得共同經歷 → 用可驗證的細節確認不是普通記錯 → 感受被抹去的不只是自己的進度，還有居民的工作、成長與相處 → 決定沿已知方向追星鏡，同時查明時間為何重複。

若完成艾梅、卡爾或其他可選支線，以相應對照增加情感；未完成者仍有必做送菜、住宿與主線旅途的共同經歷，不能預設所有玩家都認識同一批人或完成工坊紀念物。

**製作邊界**：跨輪記憶與調查方向可保留，不自動保留筆記紙張、背包、金錢、技能或 NPC 信任。回溯後位置與物件規則另定；`cycle`、`worldDay`、已知線索及 NPC 當輪記憶應分開記錄，這是後續設計要求，不代表現在已實裝輪迴。

### 第 6 章｜記得昨天的人【工作名】

**雙重目標**：一面沿觀星台記錄追查界外星鏡、尋找真正返家方法，一面查明重複時間的範圍與原因；既有目標不會因重置清空。

**故事節拍**：憑記憶重新查證資料、取得當輪人物信任 → 循殘響、鐘錶或研究線驗證世界確實回溯 → 逐步建立九十日、暮蝕與有限能源的因果 → 找到真正星鏡並檢查最初連接印記（可延展至第 7–9 章） → 驗證「有定位資料，卻沒有安全通道」 → 得到三座星錨及各地修復協作的調查方向。

**不提前補完**：誰協助、星鏡本體位置、印記如何讀取／跨輪確認、穩定度如何量測均須作者再設計。不能只因讀到裝置名稱便承諾一定能返家。

**情感推進**：這些人原本各有生活，重置卻令他們永遠無法走到第九十一日。兩人逐漸理解修復世界也在創造回家條件；關心居民是相處累積的結果，不是突然獲頒救世使命，也不是考驗情侶是否信任彼此。

**章末方向**：能源不保證還能支持下一輪；提出有技術與當地協作依據的修復方案。三錨次序暫採鑄火 → 森之 → 潮汐，並一路保留星鏡／歸途調查進度。

### 第 7 章｜鑄火之章

**時地**：工坊、礦區與第一座星錨。**暫定**：新輪第 7–25 日。

**開場**：兩人為修復鑄火星錨到達工坊，與學徒及工匠合作。若玩家曾於前輪接觸此工坊，可用熟悉與陌生的對照；未接觸者正常初識。不可假定已移出前段主線的工坊故事人人都經歷過。

**故事節拍**：找材料／辨識故障 → 工匠與健太郎合作試驗 → 奈津美用魔法維持安全及提供測量幫助 → 面對裝置啟動風險 → 修復第一錨 → 學徒以當輪自己的努力完成作品。

**情感呼應**：不是替 NPC 取回上一輪所有記憶，而是守住讓他繼續成長的條件。

**玩家互動**：安全的機關謎題、材料路線、可選工坊支線。錯誤操作可導致額外補救，不必以任意死亡懲罰。

**章末鉤子**：第一錨啟動後，出現其他兩錨失聯的明確信號。研究者可據此重新檢查星鏡連接條件；第一錨並不等於已可安全返家。

### 第 8 章｜森林不願遺忘

**時地**：魔法研究區、森林、第二座星錨。**暫定**：新輪第 26–45 日。

**開場**：在魔法研究區結識魔女學徒；若先前已有可選接觸則為再會。某份配方中的植物與當地現存記錄矛盾，可和先前旅途異常互證，不預設玩家早在第 4 章完成過配方事件。

**故事節拍**：進入有魔力流動問題的森林 → 研究法術、藥劑與植物 → 當地居民的小型生活問題與主線互相交織 → 奈津美提出實驗方案，健太郎在探索及危機時發揮作用 → 修復第二錨。

**情感描寫**：奈津美是有能力參與研究的夥伴，不是等待勇者稱讚的魔法少女；山田喜歡她展現的新一面，兩人可以有幽默的魔法失誤。

**玩家互動**：選路、植物辨認、非戰鬥魔法運用；支線不應全部變得悲壯。

**章末鉤子**：魔力恢復讓遠方一段無法辨識的星圖顯現。

### 第 9 章｜潮汐的星圖

**時地**：港口、燈塔、潮汐星錨。**暫定**：新輪第 46–65 日。

**開場**：港口某些紀錄的日期與潮汐圖不符，鐘錶匠的資料成為關鍵。

**故事節拍**：把城鎮、森林及港口三組證據對齊 → 在已知星鏡／星鐘用途上進一步驗證回程校準與時間同步條件 → 為潮汐星錨完成同步 → 確認「魔王討伐」其實可能觸發新一次災難 → 獲知北方封印守護者的存在。

**NPC 支線**：一直未能送出的信／等待歸來的人，在這裏開始有清楚的收束方向。

**玩家互動**：多線索的星圖謎題，允許玩家查閱筆記和 NPC 的協助；三座星錨修復紀錄應可檢索。

**章末鉤子**：遊戲主線的最終任務提示，與已掌握的歷史證據明顯互相衝突。

### 第 10 章｜終夜之城的守門人

**時地**：北方終夜之城、封印周圍。**暫定**：新輪第 66–78 日。

**開場**：兩人決定不盲從「擊敗魔王」指示，先調查封印真正的運作方式。

**故事節拍**：穿過高危地區 → 與受侵蝕的守門人交鋒或周旋 → 發現他一直擋住裂縫 → 不否認他因侵蝕而造成的傷害 → 找出一個既能保護居民、又不會直接毀掉封印的替代方案 → 守鐘人的立場浮現。

**關係描寫**：健太郎不是無腦衝上去殺敵；奈津美不是永遠負責勸他冷靜。讓兩人以不同優勢共同提出風險可控的策略。

**玩家互動**：戰鬥與證據蒐集並重；若有分支，應影響協助方案、代價與 NPC 後果，而非強迫角色違反既有人格。

**章末鉤子**：星鐘的最後一次重置倒數開始；若失敗，未必還有足夠能源恢復。

### 第 11 章｜逆刻星鐘

**時地**：星鐘核心／封印結構。**暫定**：新輪第 79–90 日。

**開場**：守鐘人拒絕貿然停鐘，因他曾見過真正的毀滅；兩人帶著三座星錨的修復資料與 NPC 的實際協助來到核心。

**故事節拍**：揭露當年不得不啟動星鐘的原因 → 說明繼續重置的代價 → 檢查三錨同步是否可行 → 協調守門人對裂縫的最後防護 → 讓 NPC 的專長真正參與解法 → 進行有明確失敗風險的修復 → 選擇停止輪迴。

**高潮原則**：情感是決心，**不是解題的魔法替身**；必須以先前建立的技術、線索、道具、夥伴與犧牲風險完成。可以有緊張戰鬥與危機，但不能突然出現從未預告的萬能能力。

**玩家互動**：最終多階段劇情／謎題，部分支線可帶來額外協助與尾聲變化。作者尚未決定多結局架構，暫不寫出必定存在的壞結局。

**歸途銜接**：星鏡的校準人員、所需資料與安全檢查應已沿途準備；不在終章才突然發明返家方法。處置星鐘、守門人封印與結界穩定共同影響回程，三錨啟動不能跳過其中任一項。

**章末鉤子**：星鐘停止強制回溯；世界能否真正走進第九十一日？

### 終章｜第九十一日

**時地**：第九十一日及之後的艾斯特拉，完成校準後返回現實。實際返訪、告別與啟程可以跨日，不強行把所有事情塞進第九十一日。

**開場**：時間真的繼續向前。讓居民的日常、工作與計畫以具體細節延續，不讓每個人都只停在感謝主角。不是所有人必須恢復前輪記憶，穩定世界也不等於抹去已發生的代價。

**返家節拍**：確認結界與星鐘處置後的穩定狀況 → 當地專家協助校準界外星鏡、讀取並核對最初印記、確認能量與通道安全 → 告別或返訪熟悉的人 → 建立短暫回程通道 → 兩人返回原本現實世界。第一次穿越是事故，第二次是共同準備與完成的行動。

**艾梅的條件式收束**：若玩家曾完成她的相關支線／回報石門秘密的約定，西可再坐在曬滿草藥的小屋，告訴她一路查到的事；這次不再有下一次九十日重置抹去相處的威脅。未走該支線仍可完整返家，以實際認識的其他人物承接餘韻，不虛構共同回憶。

**情感收束**：最初只想好好過一個普通星期六；之後想回家；沿途的人成為兩人願意為之努力的生活。最後創造同時容納「返家」與「讓居民有第九十一日」的未來。兩人本已穩定信任，結尾仍能像原本那樣自然說話、互相逗笑。

**仍待精密設計**：現實過了多久、回到哪個時間／位置、身體與外貌如何對應、是否可再聯絡或往返。只確立回到原世界，不預設同一星期六、同一秒或永久失聯。後日談與多結局架構須另批。

| SQ-FORGE | 鐵匠學徒（勿自動等同卡爾） | 後續工坊章，確切首次登場待定 | 成長與被忘記的友情 | 修復工藝／星錨額外支援 | 主線會認識；額外委託可選 |

| SQ-CLOCK | 鐘錶匠／時間研究者，身份待定 | 途中異常至第 6 章，正式登場待定 | 記憶、證據與時間 | 重置證據、潮汐同步幫助 | 主線關鍵 |

**埃斯特拉村既有七支線**：沿用《第一份工錢》《旅舍忙碌的一晚》《曬在窗邊的草藥》《木匠的工作台》《說好了要保密》《走不到的北路》《兩張不一樣的貨單》的規劃。上表是後續地區功能線，不覆蓋村莊清單，不因舊大綱換章而強迫重做角色專屬支線。

**艾梅的線索接口**：她的鏡面石門傳聞是提早識別與專屬互動；必要的「觀測地點」證據與下一步方向由驛站／城史主線兜底。既不要求選西完成專屬支線，也不讓未完成支線的玩家缺少核心推理證據。

**重置後支線狀態**：先區分「玩家跨輪記得什麼」與「NPC 當輪認為發生了什麼」。避免支線直接沿用前一輪的 NPC 信任值而自相矛盾。已知道的線索可幫主角重新取得信任，但不應令 NPC 平白認得兩人。

## E. 為互動文字遊戲設計的選擇框架

- **風味型選擇**：不同俏皮對話、飯菜、先看哪份介紹；不改變兩人的核心人設。
- **順序型選擇**：先探索工坊、先訪問鐘錶匠、先研究配方；改變資訊呈現次序，最後回到必要主線。
- **支線型選擇**：接受或延後幫助某個 NPC；帶來角色互動、道具、CG、後日談差異。
- **解謎型選擇**：由收集證據推論規則，允許錯誤後重試及求助，避免一個答案堵死故事。
- **關鍵抉擇**：處理守門人、是否冒險停止星鐘；選項必須有充分資訊與可理解代價。結局數目待作者批准。

**不適合的機制**：以「愛情好感度」懲罰玩家令情侶忽然冷漠、強迫奈津美在社交場合失能、為戲劇效果讓健太郎經常無視奈津美意願。

## F. 製作順序與驗收點（供 Codex）

1. 先把雙視角序章原稿以獨立資料檔匯入，保留原文，建立兩個觀點的切換及共用時間點。
2. 建立第 1–2 章小型可玩原型：對話、選項、場景背景、立繪版本切換、事件旗標、回顧及存讀檔。
3. 前段先驗收五段線索、每段合理誤解、石門實測與觀星台方向；再證明「有共同經歷 → 得知星鏡調查方向 → 重置 → NPC 忘記、主角仍有目標」的狀態鏈。缺少任何可選村莊支線亦須可走通。
4. 後續章節依星錨逐一增加系統，而非一次建完戰鬥、背包、工藝及時間模擬。
5. 每完成一章核對：人物語氣、雙視角時間、NPC 的當輪記憶、已取得的線索、輪迴時間及可用技能。

**素材規劃（初步）**：現實山田、現實西、勇者山田、魔女西四套立繪；各自不同表情；家中、學校／街道、小鎮、工坊、魔法研究室、森林、港口、王都、終夜之城、星鐘核心等背景；日常與冒險 CG。正式素材清單可於分鏡完成後獨立整理。

## G. 必須由作者再拍板的創作問題

1. 最初星鏡異常共鳴為何發生？同機雙人操作、遊戲石門場景與實體跨界之間的精確條件是甚麼？角色外貌／肉身如何對應？
2. 世界中的遊戲 UI 是真實可見、只有主角可見，還是隨時間逐漸消失？
3. 完整九十日的日期、地區旅行時間和任務時長如何安排？
4. 記憶／道具／裝備跨輪的處置；NPC 與來者在重置瞬間所處位置的規則。
5. 受傷、死亡與治療的實際代價，避免輕率設定。
6. 守鐘人、守門人正式人格與過去；是否真有能與之對話的轉機？
7. 最終是單一主結局＋支線尾聲變化，還是存在有因果的多結局？
8. 界外印記如何儲存、辨認原世界、經歷回溯後仍可追查？現實經過多久、返鄉時間／位置及之後能否接觸艾斯特拉？
9. 舊觀星台殘記的來源、缺失內容、星鏡本體所在地與首次重置前的具體下一調查目標；不能自行補成裝置就在觀星台。
10. 星鏡的能量、安全與校準程序，何時可提出返家技術方案，如何讓各地專家參與而不一次解說所有規則？

> **主線綱領**：古石門引出界外星鏡；星鏡給回家可行的依據；九十日輪迴與受損結界阻礙回程；修復世界，才讓兩人回家與居民迎來第九十一日同時成立。山田與西的關係始終穩固，返家目標始終存在；變化的是他們對世界的理解，以及一路建立的關係。
