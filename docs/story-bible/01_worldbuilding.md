# 01｜世界觀設定：艾斯特拉與逆刻星鐘

> **使用說明**：供作者與 Codex 作為創作依據。標記 **【確立】** 為已在對話中確認的方向；**【暫定】** 為目前採納的工作方案，之後仍可修改；**【待定】** 不得擅自補成既定事實。本文含後期劇透，不應直接公開成遊戲內的世界介紹。

## 1. 作品定位與不可動搖的基礎

**【確立】** 這是一款以《正反対な君と僕》山田健太郎×西奈津美為主角的二次創作文字遊戲，從**現實世界的戀愛日常**，自然過渡至**雙人合作幻想 RPG**，並在冒險中展開世界異常的懸疑主線。採用「**B：王道冒險＋世界秘密**」作主線，以「**C：地區與 NPC 人物故事**」作重要支線；解謎與 NPC 的人生、記憶和命運同樣重要。

**【確立】** 故事開始時兩人已交往數年，感情穩定。山田就讀**自動車專門學校**，西就讀大學。山田外向、直率、行動力強，但尊重西的選擇與節奏；對西而言，他近乎是理想的男友。西依然安靜內向、笑點低、有自己的主見；到大學時已能和同學自然交談，不會因普通社交而頻繁緊張，只是不擅長主動找陌生人攀談。彼此稱呼：山田叫「**奈津美**」，西叫「**健太郎**」。旁白可使用姓氏。

**【確立】** 已有雙視角序章：西視角《終於有時間了》、山田視角《比誰都期待的星期六》。西考完期末考、同學介紹熱門合作遊戲、兩人約定星期六在山田家用同一台主機玩、山田立即購買、兩人預選勇者與魔女。序章結束在約會前夕。具體原文以作者提供的稿件為唯一準本，不應由開發工具自行重寫。

**作品情緒曲線**：溫暖日常 → 輕快探索 → 奇妙的違和感 → 失去「共同經歷」的刺痛 → 揭露輪迴與守護的代價 → 攜手尋找可實現的解法 → 世界迎接真正的明天。全篇必須保留幽默、甜蜜、旅途生活感，不能突然改成通篇絕望恐怖，也不能依靠情侶失信、分手或誤會製造主線張力。

## 2. 世界的「公開版本」（遊戲內初始資訊）

**【暫定】世界名：艾斯特拉（Estella）**。一片由王國、城鎮、森林、港灣、古代遺跡組成的魔法大陸。一般人有工作、家庭、節日、煩惱與夢想；並非一切都為勇者主線而存在。冒險者公會提供委託，工匠維護裝備，魔法學徒研究配方，商販與旅人穿梭各地。

大陸傳說：古老的**「暮蝕」**將吞沒星光、令魔物狂暴。勇者與魔女必須合作，取得古代遺物，走向北方的**終夜之城**，擊敗傳說中的**「魔王」**，帶來黎明。普通玩家、甚至多數當地居民，都只知道這個王道故事。

故事初期可存在部分 RPG 介面／提示（職業、技能、地圖、任務等）；但這個世界具有真實觸感、連續的生活與真切的人際關係。**「遊戲介面顯示」不等於世界客觀真相**；介面可能沿用開發者對世界的誤解。

### 地區骨架【暫定】

| 區域 | 表層作用 | 深層劇情用途 |
|---|---|---|
| 初始小鎮／冒險者公會 | 新手任務、補給、第一次認識 NPC | 與居民建立情感；重置後失去共同經歷 |
| 鍛造城鎮 | 工坊、裝備與礦區 | **鑄火星錨**；鐵匠學徒支線，讓健太郎的實作興趣有用武之地 |
| 森林與魔法研究區 | 藥草、魔法學習、遺跡 | **森之星錨**；魔女學徒與缺失配方的謎團 |
| 潮汐港／燈塔 | 海路、星圖、時間測算 | **潮汐星錨**；跨輪迴的日期證據 |
| 王都與古代書庫 | 傳說、王國歷史、主線資訊 | 公開歷史與真實記錄發生矛盾 |
| 北方終夜之城 | 傳說的魔王所在之地 | 最後封印、守門人真相與高潮 |
| 逆刻星鐘核心 | 早期不可抵達 | 輪迴機制、最終修復與抉擇 |

地名僅為功能標籤；尚未定正式譯名、距離、地圖比例、交通時間或王國政體細節。

## 3. 世界真正發生的事情（作者劇透層）

### 3.1 災難與最初的選擇【暫定】

幾百年前，維持大陸魔法秩序的**古代結界**遭到暮蝕侵蝕，核心裂開。裂縫若擴大，將引發魔力失控、魔物異常與地區崩解。當時的研究者無法及時完成永久修復，只能啟動禁忌裝置——**逆刻星鐘**——爭取時間。

星鐘並**不是**治癒世界的裝置；它只能把世界回溯到同一段時間的起點，推遲災難爆發。當世界再次走到臨界點，回溯再度啟動。

### 3.2 九十日輪迴【暫定】

- 每輪的理論長度為**九十日**，從「**原初日**」起至暮蝕達到臨界。可由星鐘的緊急保護程序提早觸發，但必須於劇情中建立因果，不可任意改日期。
- 回溯後，多數地形、物件、居民的身體狀況和當輪記憶回到原初日的狀態。對本人而言，無法察覺已經活過許多輪。
- **兩位界外來者**——健太郎和奈津美——因與界外星鏡連接，**保留跨輪記憶**；這是追查謎團的必要條件，並非戀愛力量自動破解魔法。
- **記憶保留不等於物品保留**。人物、背包、裝備和地點如何處理仍屬【待定】，開發時不可假設玩家可無限複製物資或任意帶走跨輪道具。
- 第一次重置安排在故事約三分之一處。兩人進入世界時，這一輪**已接近尾聲**，故不需要讓他們在前期完整度過九十天。
- 每次回溯都消耗維持結界所需的**星核能量**。能源有限；重置愈多，永久修復的時間與機會愈少。

**設計意義**：重置對兩名主角而言是「記得」，對當地大部分居民而言是「被抹去卻不知情」。玩家第一次遇到重置時，應已經和一些 NPC 建立真實情感，而不是先聽完機制說明。

### 3.3 殘響：為何世界會留下破綻？【暫定】

星鐘並不完美。魔力裂縫附近的特定物件、記錄或場所，可能留下前一輪的**「殘響」**：不完整的影像、夢、時間不合的筆記、明明未曾認識卻有熟悉感的人。殘響不是普遍的前世記憶，更不是只要意志堅定就一定覺醒。它必須有可追溯的**場所、物件或魔法異常作為媒介**。

例子：鐘錶匠夢到自己從未打造過的鐘；一本配方書記錄已不存在的植物；某戶人家收著日期晚於今日的信。前期看似可用記錯、做夢或惡作劇解釋，後期才組成相互支持的證據鏈。

### 3.4 被誤解的「魔王」【暫定】

終夜之城裡的「魔王」原本是**暮蝕封印的守門人**。長年受侵蝕，力量與外觀變得可怖，周遭魔物聚集，於是被傳說誤認為災難源頭。實際上，他仍在用自身力量支撐最後一層封印。

**直接殺死守門人，可能令封印失守並啟動星鐘緊急重置**，使傳統「討伐魔王＝通關」變成另一輪循環的起點。但守門人並非毫無危險的善人：漫長侵蝕也可能使他失控、造成實際傷害。角色必須有責任與代價，反轉不能簡化為「大家誤會了，停止戰鬥就好」。

### 3.5 守鐘人的道德困境【暫定】

**守鐘人**了解輪迴全貌，負責維持星鐘；曾見識未被保護的世界如何崩解。其立場並非純粹邪惡，而是「不敢把全部生命押在一次可能失敗的修復上」。他知道循環不能永遠持續，但認為繼續重置至少可維持短暫的存在。

主角不只需要戰勝危機，還需要提出**有技術可行性、有 NPC 參與、有風險處理**的替代方案，才能使守鐘人有理由停止循環。

## 4. 三座星錨：可行的解法【暫定】

**星錨**是維持原初結界的古代穩定裝置，不是收集三顆寶石就自動世界和平。它們失修、失聯或欠缺同步，必須分別找到真正的修復方法。恢復三座星錨的結構與協調後，才能穩定結界、減少對星鐘的依賴。

| 星錨 | 作用 | 需要的能力與夥伴 | 故事價值 |
|---|---|---|---|
| **鑄火星錨** | 修復結界的結構與能量傳導 | 鐵匠、金屬材料、實作分析；山田能觀察機構，但不是突然變成萬能工程師 | 工匠的努力能持續到明天 |
| **森之星錨** | 穩定魔力流量 | 藥劑、古文、植物、魔法研究；奈津美有好奇心與研究能力，但需當地專家合作 | 探究失傳知識與居民的願望 |
| **潮汐星錨** | 令其他星錨與星鐘同步 | 星圖、鐘錶、時間記錄、港口與燈塔資料 | 將分散的殘響整理成可驗證的輪迴證據 |

三座星錨修復後，仍須處理**守門人支撐的封印裂縫**，並處置**逆刻星鐘的最後一次啟動風險**。最終章不能繞過之前的知識、物資、盟友與代價。

## 5. 為何現實世界有這款遊戲？【暫定】

**遊戲沒有創造艾斯特拉。** 艾斯特拉原本就是獨立存在的世界。古代的**界外星鏡**曾被設計用來向世界之外尋求援助，長年把不完整的影像與輪迴片段送向現實。現實世界的一名遊戲開發者因反覆夢見這些片段，誤以為是個人靈感，把它們整理成雙人合作 RPG。

因此，「遊戲原有劇情」並非完整的歷史，可能把不同輪迴、流言、虛構補完混在一起。主角所見的某些任務文案會誤導，但不代表所有 NPC 都只是程式碼。

**穿越機制【暫定】**：兩人開始遊戲時，雙人連線與星鏡在一次罕見共鳴中形成界外通道，令兩人以遊戲角色的勇者與魔女外貌進入艾斯特拉。此機制不應表述成「因為情侶有命運羈絆，所以被選中」。

**返鄉機制【待定】**：理想方案是待星鏡與結界穩定後重開通道，但是否需要額外代價、現實流逝多少時間、能否與 NPC 保持聯絡，都尚未決定。

## 6. NPC 生活與支線設計原則

**【確立】** NPC 首先是「會生活的人」，不是獎勵販賣機。每個重要 NPC 至少有：日常身份／當下願望／實際困難／與兩位主角的連結／不完成支線時仍會繼續的人生。人物故事可以幽默、細小、溫暖，也可與輪迴謎團相連；不要求人人都有悲慘過去。

**【暫定】人物線索**：

1. **鐵匠學徒**：努力學做出一件真正滿意的作品；第一次重置後忘記了與兩人的友誼。成為玩家理解「被奪走的成長」的第一個情感錨點。
2. **魔女學徒**：熱情、有創意但常把配方弄錯；與奈津美共同研究，某一本舊配方記錄了不該存在的植物。
3. **鐘錶匠**：記得未曾發生的「昨天」；其物件與記錄證明殘響並非單純幻覺。
4. **郵差／等待收信的人**：每次都差一點送達的信件；提供「等不到的明天」之情感視角。
5. **普通城鎮居民**：店主、孩子、旅人、家庭；提供純生活支線、笑點與喘息，不必每個都牽涉陰謀。

**支線與主線的接口**：支線可提供線索、特殊協助、工藝方案、可選 CG 或尾聲變化；但基本主線可在沒有全清支線的情況下理解與完成。不要把 NPC 感情量化為「幾點好感值換一顆救贖水晶」。

## 7. 角色在世界裡的能力邊界

- **山田／勇者**：近戰、保護、探索、實作直覺；能與工匠交流、主動接近 NPC，也會學習新的戰鬥方法。**不可**固定成莽撞闖禍、看不懂局勢、強迫奈津美跟隨的男人。
- **西／魔女**：法術、輔助、研究、藥劑、環境互動；能自然與 NPC 溝通，願意主動探索感興趣的事。**不可**固定成見人便緊張、只能被救的少女。
- 兩人都會犯操作錯誤、開玩笑、一起學習，能有各自主導的章節。他們早已有感情安全感，遊戲不設「一個選項令兩人感情歸零」的懲罰。
- 魔法、傷勢、死亡、治療、復活及物資持久化尚待規則化；**不能因劇情方便而忽然無限施法或無代價復活**。

## 8. 故事邏輯鏈（主線必須可追溯）

1. 古代結界受暮蝕侵蝕 → 世界有真實滅亡危機。
2. 研究者啟動逆刻星鐘 → 用回溯代替修復，暫時保住居民。
3. 反覆重置消耗星核 → 世界長期未來愈來愈短，居民的成長與記憶不斷被抹去。
4. 星鐘不完美 → 殘響留下矛盾證據；某些人、某些物件對「昨天」產生錯亂感。
5. 界外星鏡外洩歷史片段 → 現實世界出現一款看似虛構、實則部分取材自真世界的 RPG。
6. 健太郎與奈津美因雙人遊戲共鳴進入 → 能保留輪迴記憶，發現任務文案與現實不一致。
7. 傳統「討伐魔王」會誤傷守門人 → 可能使封印崩潰，強制再來一次。
8. 兩人與 NPC 尋找、修復並同步三座星錨 → 才有不依賴重置的實際方案。
9. 面對守門人的封印與守鐘人的選擇 → 經證據、盟友、行動與風險控制令世界真正往前。
10. 終於迎來第九十一日 → 居民的努力第一次不會被時間抹去；兩人再尋求歸途。

## 9. 懸念揭露節奏（寫作者版）

| 階段 | 玩家可以知道 | 暫時不可明說 |
|---|---|---|
| 序章與第 1 章 | 兩人約會、遊戲宣傳的王道傳說 | 任何輪迴真相 |
| 第 2–3 章 | 進入遊戲世界、角色與觸感是真實的、認識 NPC | 星鐘、星錨完整機制 |
| 第 4 章 | 日期／配方／夢境出現可信的矛盾 | 重置全貌與真正來源 |
| 第 5 章 | 世界回到原初日、主角記得、NPC 忘記 | 星鐘代價與魔王真相 |
| 第 6–9 章 | 殘響、星錨、耗能、守鐘人資料逐步組合 | 最終處置方案須待證據齊全 |
| 第 10–11 章 | 守門人身分、封印與重置的完整因果 | 不再需要藏重大機制，應轉向行動高潮 |
| 終章 | 真正的明天與角色餘韻 | 可保留少量想像空間，不用強開續集伏筆 |

## 10. 未定義事項與後續設計檢查

**【待定】** 世界正式名稱、具體地圖、年代／曆法、角色及 NPC 正式姓名、王國制度、職業進階、技能成本、戰敗處置、玩家可回溯的權限、遊戲 UI 何時消失、星鐘能否提前觸發、外來者物品回溯、NPC 殘響保留精度、現實時間流速、返鄉方法、多結局數目。

**寫作／實作前檢查**：每章至少回答「這章推進了哪個目標？發現了甚麼新的可驗證證據？哪個 NPC 的願望受到影響？兩位主角是否仍像自己？有哪些規則不能被忽略？」。若設定尚未確認，Codex 應使用 `TBD`，不可默默補寫成世界真相。
