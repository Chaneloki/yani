# 01｜世界觀設定：艾斯特拉與逆刻星鐘

> **使用說明**：供作者與 Codex 作為創作依據。標記 **【確立】** 為已在對話中確認的方向；**【暫定】** 為目前採納的工作方案，之後仍可修改；**【待定】** 不得擅自補成既定事實。本文含後期劇透，不應直接公開成遊戲內的世界介紹。

> **2026-11-06 修訂**：採納「古石門誤判 → 舊觀星台 → 界外星鏡 → 輪迴阻礙歸途 → 第九十一日後返家」主線。以下【確立｜主線方向】指本次採納的因果與揭露順序；裝置的精密規則仍依【暫定】／【待定】管理。作者設定層不等於角色已知資訊。

## 1. 作品定位與不可動搖的基礎

**【確立】** 這是一款以《正反対な君と僕》山田健太郎×西奈津美為主角的二次創作文字遊戲，從**現實世界的戀愛日常**，自然過渡至**雙人合作幻想 RPG**，並在冒險中展開世界異常的懸疑主線。採用「**B：王道冒險＋世界秘密**」作主線，以「**C：地區與 NPC 人物故事**」作重要支線；解謎與 NPC 的人生、記憶和命運同樣重要。

**【確立】** 故事開始時兩人已交往數年，感情穩定。山田就讀**自動車專門學校**，西就讀大學。山田外向、直率、行動力強，但尊重西的選擇與節奏；對西而言，他近乎是理想的男友。西依然安靜內向、笑點低、有自己的主見；到大學時已能和同學自然交談，不會因普通社交而頻繁緊張，只是不擅長主動找陌生人攀談。彼此稱呼：山田叫「**奈津美**」，西叫「**健太郎**」。旁白可使用姓氏。

**【確立】** 已有雙視角序章：西視角《終於有時間了》、山田視角《比誰都期待的星期六》。西考完期末考、同學介紹熱門合作遊戲、兩人約定星期六在山田家用同一台主機玩、山田立即購買、兩人預選勇者與魔女。序章結束在約會前夕。具體原文以作者提供的稿件為唯一準本，不應由開發工具自行重寫。

**作品情緒曲線**：溫暖日常 → 輕快探索 → 奇妙的違和感 → 失去「共同經歷」的刺痛 → 揭露輪迴與守護的代價 → 攜手尋找可實現的解法 → 世界迎接真正的明天。全篇必須保留幽默、甜蜜、旅途生活感，不能突然改成通篇絕望恐怖，也不能依靠情侶失信、分手或誤會製造主線張力。

## 2. 世界的「公開版本」（遊戲內初始資訊）

**【暫定】世界名：艾斯特拉（Estella）**。一片由王國、城鎮、森林、港灣、古代遺跡組成的魔法大陸。一般人有工作、家庭、節日、煩惱與夢想；並非一切都為勇者主線而存在。冒險者公會提供委託，工匠維護裝備，魔法學徒研究配方，商販與旅人穿梭各地。

大陸傳說：古老的**「暮蝕」**將吞沒星光、令魔物狂暴。勇者與魔女必須合作，取得古代遺物，走向北方的**終夜之城**，擊敗傳說中的**「魔王」**，帶來黎明。普通玩家、甚至多數當地居民，都只知道這個王道故事。

故事初期可存在部分 RPG 介面／提示（職業、技能、地圖、任務等）；但這個世界具有真實觸感、連續的生活與真切的人際關係。**「遊戲介面顯示」不等於世界客觀真相**；介面可能沿用開發者對世界的誤解。

## 3. 世界真正發生的事情（作者劇透層）

### 3.1 災難與最初的選擇【暫定】

幾百年前，維持大陸魔法秩序的**古代結界**遭到暮蝕侵蝕，核心裂開。裂縫若擴大，將引發魔力失控、魔物異常與地區崩解。當時的研究者無法及時完成永久修復，只能啟動禁忌裝置——**逆刻星鐘**——爭取時間。

星鐘並**不是**治癒世界的裝置；它只能把世界回溯到同一段時間的起點，推遲災難爆發。當世界再次走到臨界點，回溯再度啟動。

### 3.2 九十日輪迴【暫定】

- 每輪的理論長度為**九十日**，從「**原初日**」起至暮蝕達到臨界。可由星鐘的緊急保護程序提早觸發，但必須於劇情中建立因果，不可任意改日期。
- 回溯後，多數地形、物件、居民的身體狀況和當輪記憶回到原初日的狀態。對本人而言，無法察覺已經活過許多輪。
- **兩位界外來者**——健太郎和奈津美——因與界外星鏡連接，**保留跨輪記憶**；這是追查謎團的必要條件，並非戀愛力量自動破解魔法。
- **記憶保留不等於物品保留**。人物、背包、裝備和地點如何處理仍屬【待定】，開發時不可假設玩家可無限複製物資或任意帶走跨輪道具。
- **【確立｜揭露順序】** 第一次讓玩家親歷的重置，發生在古石門失敗之後：兩人已到舊觀星台讀到界外星鏡殘缺記錄，並取得下一個調查方向，星鐘才啟動。這不是世界歷史上的第一次輪迴。兩人此時尚不知道九十日循環的存在。
- **【暫定】** 敘事約三分之一處進入這次重置；兩人抵達時本輪已接近尾聲。確切進入日、旅程長度、是否於第九十日正常啟動，必須另排日曆。生活玩法的「抵達後第幾日」不可直接當作輪迴日數。
- 每次回溯都消耗維持結界所需的**星核能量**。能源有限；重置愈多，永久修復的時間與機會愈少。

**設計意義**：重置對兩名主角而言是「記得」，對當地大部分居民而言是「被抹去卻不知情」。玩家第一次遇到重置時，應已經和一些 NPC 建立真實情感，而不是先聽完機制說明。

### 3.3 殘響：為何世界會留下破綻？【暫定】

星鐘並不完美。魔力裂縫附近的特定物件、記錄或場所，可能留下前一輪的**「殘響」**：不完整的影像、夢、時間不合的筆記、明明未曾認識卻有熟悉感的人。殘響不是普遍的前世記憶，更不是只要意志堅定就一定覺醒。它必須有可追溯的**場所、物件或魔法異常作為媒介**。

例子：鐘錶匠夢到自己從未打造過的鐘；一本配方書記錄已不存在的植物；某戶人家收著日期晚於今日的信。前期看似可用記錯、做夢或惡作劇解釋，後期才組成相互支持的證據鏈。

### 3.4 被誤解的「魔王」【暫定】

終夜之城裡的「魔王」原本是**暮蝕封印的守門人**。長年受侵蝕，力量與外觀變得可怖，周遭魔物聚集，於是被傳說誤認為災難源頭。實際上，他仍在用自身力量支撐最後一層封印。

**直接殺死守門人，可能令封印失守並啟動星鐘緊急重置**，使傳統「討伐魔王＝通關」變成另一輪循環的起點。但守門人並非毫無危險的善人：漫長侵蝕也可能使他失控、造成實際傷害。角色必須有責任與代價，反轉不能簡化為「大家誤會了，停止戰鬥就好」。

### 3.5 守鐘人的道德困境【暫定】

**守鐘人**了解輪迴全貌，負責維持星鐘；曾見識未被保護的世界如何崩解。其立場並非純粹邪惡，而是「不敢把全部生命押在一次可能失敗的修復上」。他知道循環不能永遠持續，但認為繼續重置至少可維持短暫的存在。

主角不只需要戰勝危機，還需要提出**有技術可行性、有 NPC 參與、有風險處理**的替代方案，才能使守鐘人有理由停止循環。

## 4. 三座星錨：可行的解法【暫定】

**星錨**是維持原初結界的古代穩定裝置，不是收集三顆寶石就自動世界和平。它們失修、失聯或欠缺同步，必須分別找到真正的修復方法。恢復三座星錨的結構與協調後，才能穩定結界、減少對星鐘的依賴。

| 星錨 | 作用 | 需要的能力與夥伴 | 故事價值 |
|---|---|---|---|
| **鑄火星錨** | 修復結界的結構與能量傳導 | 鐵匠、金屬材料、實作分析；山田能觀察機構，但不是突然變成萬能工程師 | 工匠的努力能持續到明天 |
| **森之星錨** | 穩定魔力流量 | 藥劑、古文、植物、魔法研究；奈津美有好奇心與研究能力，但需當地專家合作 | 探究失傳知識與居民的願望 |
| **潮汐星錨** | 令其他星錨與星鐘同步 | 星圖、鐘錶、時間記錄、港口與燈塔資料 | 將分散的殘響整理成可驗證的輪迴證據 |

三座星錨修復後，仍須處理**守門人支撐的封印裂縫**，並處置**逆刻星鐘的最後一次啟動風險**。最終章不能繞過之前的知識、物資、盟友與代價。

## 5. 古石門、界外星鏡與真正的歸途

### 5.1 遊戲與世界的關係【沿用暫定設定】

**遊戲沒有創造艾斯特拉。** 艾斯特拉原本就是獨立存在的世界。古代的**界外星鏡**為向世界之外尋求援助而建造，曾將不完整的世界影像與輪迴片段傳向現實。一名開發者反覆夢見這些景象，將其當作靈感整理成雙人合作 RPG。

遊戲會混合不同輪迴的片段、流言與開發者的虛構補完；介面和任務文案不是客觀歷史。主角能據遊戲提出合理假說，但必須用實地證據修正。

### 5.2 四個裝置／狀態的功能界線【確立｜主線方向】

| 元素 | 真正作用 | 不可混淆的界線 |
|---|---|---|
| 古石門 | 與古代觀測活動相關的遺跡；測量刻紋可與舊地圖、城史互證 | 不能跨越世界；中央圓鏡不等於界外星鏡，也不是星鏡的便利替代品 |
| 界外星鏡 | 真正曾與現實建立聯繫、保存最初連接印記的古代裝置 | 找到它不代表可立即返家；舊觀星台有研究記錄，不表示裝置本體必在那裡 |
| 逆刻星鐘與九十日輪迴 | 回溯世界以推遲暮蝕；反覆重設時空狀態 | 是安全、穩定建立回程通道的根本障礙之一；不是星鏡本身的傳送功能 |
| 修復結界並迎來第九十一日 | 三錨、封印及星鐘處置共同建立世界持續向前的條件 | 創造星鏡可穩定運作的條件；仍須專家校準與確認，不能自動瞬移返家 |

### 5.3 第一次穿越：意外共鳴【採用的機制工作方案】

兩人在山田家，於同一部主機操作雙人 RPG；遊戲演到古石門啟動時，艾斯特拉一側的界外星鏡恰好出現異常共鳴。兩側訊號短暫重合，造成一次原本不應發生的實體跨界，兩人以勇者／魔女外貌進入世界。

白光與穿越都是真實經歷，**真正造成跨界的是星鏡共鳴，並非古石門**。同步發生令他們誤認因果；這個誤判符合當時資訊，不代表角色愚蠢。事故不是因兩人命中注定、被選為救世勇者，也不是戀愛羈絆提供魔力。

**【待定】** 這次異常為何恰在當時發生、訊號如何形成實體通道、與雙人操作的必要條件及頻率，均須另行設計；不能用巧合概括後便任意重複發生。

### 5.4 回程定位：界外印記【確立用途；精密規則待定】

星鏡記錄最初與山田家遊戲裝置連接的獨特訊號，暫稱**界外印記**；它承擔「原世界回程定位資料」的敘事功能。兩人須找到真正星鏡，檢查印記是否存在與可讀，返家才由希望成為有證據支持的技術可能。

印記不直接顯示日本地址，不是可輸入任意地點的座標，也不容許玩家隨時開門。**記錄如何儲存、識別哪一個現實連接，以及經過重置後如何仍能追查／確認，皆為【待定】**；不可因此預設整部星鏡或所有研究筆記都免於回溯。

### 5.5 為何找到星鏡仍不能直接使用？【確立｜主線方向】

九十日回溯反覆重設艾斯特拉的時空狀態，受損結界又使跨世界連接極不穩定。星鏡可能具備定位資料，卻沒有可安全承載兩人返回的穩定通道。具體檢測、故障證據與安全標準留待機制設計，不以一名 NPC 的宣告代替驗證。

兩人因此必須沿途與研究者、工匠及各地居民合作，修復並同步三座星錨，處理封印裂縫與星鐘強制回溯。**尋找歸途與解除輪迴逐漸交會；回家的目標不會被「突然接受拯救世界的使命」取代。**

### 5.6 第九十一日與雙向共鳴返家【確立｜結局方向】

世界真正走到第九十一日之後，穩定結界與停止強制回溯提供安全運作條件。當地專家協助校準星鏡、核對印記、能量與通道穩定度，兩人才以最初連接為依據，建立短暫回程通道，返回原本的現實世界。

第一次跨界是事故；第二次是兩人與當地居民共同準備、驗證並完成的行動。修復世界同時讓居民擁有明天、讓兩人得以回家；不強迫在兩者間二選一。第九十一日是穩定條件成立的里程碑，**不是所有返訪、校準和歸家必須在同一天做完**。

**【待定】** 現實經過多久、返回的時間與位置、異世界外貌／身體和現實身體的對應、能量需求或額外代價、能否再次往返／聯絡。不得先寫成「回到原來星期六的同一秒」，也不得擅加必須分離、犧牲一人等條件。

### 5.7 前往古石門的五段線索鏈【確立｜鋪陳原則】

| 地點與眼前需要 | 局部資訊 | 當時合理理解 | 後來的重讀與主線兜底 |
|---|---|---|---|
| 埃斯特拉村：賺生活費、問路、等待商隊 | 艾梅談鏡面石門傳聞；奧倫介紹商道與驛站的舊路資料 | 城外可能有與遊戲相同、可回家的門 | 艾梅為可選提早線索；奧倫／驛站主線保證調查可繼續 |
| 山間驛站：核對實際道路 | 舊商隊圖將古石門標為「觀測地點」，並非出口 | 也許要配合星位才能啟動石門 | 石門測量標記讓「觀測」重新獲得字面意義 |
| 前往星燈之城：因路況、器物或旅人記錄而接觸異常 | 無法解釋的星光與時間記錄 | 儀器失準、抄錄有誤或個別怪事 | 後續鐘聲、星象矛盾互證；此時不能直接確證輪迴 |
| 星燈之城：查找石門與城史 | 古人曾觀測「天空以外的地方」；城中有舊觀星台相關記錄 | 古代天文研究，或石門啟動方法的一部分 | 城史、地圖與石門同款星紋指出觀星台這個具體地點 |
| 城外古石門：親自嘗試返家 | 外形吻合遊戲卻無法跨界；刻紋更像方位／星象測量標記 | 原本的啟動假說可能錯了 | 兩人比對既有資料，主動決定回城調查舊觀星台 |

NPC 只知道其生活中接觸的一部分。線索由眼前需求引出，不按地點輪流安排世界觀講解員。古石門的失敗是**推理轉折**，不是只剩絕望或等待學者送答案。西整理筆記，山田記得站位、觀察實物並認出圖上相同星紋；兩人共同完成修正假說。

### 5.8 舊觀星台與第一次可見重置【確立｜揭露順序】

古石門失敗 → 比對圖記，找到舊觀星台 → 讀到殘缺古研究記錄中的「界外星鏡」及向另一世界傳訊的用途 → 對遊戲與艾斯特拉的相似得到第一個可能解釋 → 著手追查裝置，確定下一個調查方向 → 星鐘在玩家面前啟動，世界回到原初日。

這時兩人**尚未**掌握印記、穩定回程、九十日長度或星鐘原理。鐘聲與時間對不上、星象記錄矛盾、天空變化先逐步加劇，再由親歷重置形成不可否認的問題。具體下一個調查地點尚未命名，不由文件自行補完。

重置後，兩人保留共同經歷與已知調查方向，NPC 大多忘記。第二輪同時追查星鏡與重複時間的原因；之後才逐步明白暮蝕、有限能源與星鐘的守護代價。主角記得某頁記錄，**不等於那張紙實物也跨輪保留**。

## 6. NPC 生活與支線設計原則

**【確立】** NPC 首先是「會生活的人」，不是獎勵販賣機。每個重要 NPC 至少有：日常身份／當下願望／實際困難／與兩位主角的連結／不完成支線時仍會繼續的人生。人物故事可以幽默、細小、溫暖，也可與輪迴謎團相連；不要求人人都有悲慘過去。

**【暫定】人物線索**：

1. **鐵匠學徒**：努力學做出一件真正滿意的作品；若前輪曾建立友誼，重置後會忘記共同經歷，可加深「被奪走的成長」的感受；未走工坊支線者以主線已認識的村民與旅人承接，不強迫這名學徒作第一個情感錨點。
2. **魔女學徒**：熱情、有創意但常把配方弄錯；與奈津美共同研究，某一本舊配方記錄了不該存在的植物。
3. **鐘錶匠**：記得未曾發生的「昨天」；其物件與記錄證明殘響並非單純幻覺。
4. **郵差／等待收信的人**：每次都差一點送達的信件；提供「等不到的明天」之情感視角。
5. **普通城鎮居民**：店主、孩子、旅人、家庭；提供純生活支線、笑點與喘息，不必每個都牽涉陰謀。

**艾梅與歸途線【確立｜可選支線原則】**：未完成艾梅支線時，主線仍經奧倫／驛站記錄取得古石門與觀測地點的調查方向；完成時可更早認出傳聞與遺跡的關聯，並有專屬對話。終章返訪她的草藥小屋、由西回報石門秘密，是完成該支線／相關約定後的可選情感呼應，不是返家必要門檻，也不能讓未見過她的玩家憑空擁有約定。

**支線與主線的接口**：支線可提供線索、特殊協助、工藝方案、可選 CG 或尾聲變化；但基本主線可在沒有全清支線的情況下理解與完成。不要把 NPC 感情量化為「幾點好感值換一顆救贖水晶」。

## 7. 角色在世界裡的能力邊界

- **山田／勇者**：近戰、保護、探索、實作直覺；能與工匠交流、主動接近 NPC，也會學習新的戰鬥方法。**不可**固定成莽撞闖禍、看不懂局勢、強迫奈津美跟隨的男人。
- **西／魔女**：法術、輔助、研究、藥劑、環境互動；能自然與 NPC 溝通，願意主動探索感興趣的事。**不可**固定成見人便緊張、只能被救的少女。
- 兩人都會犯操作錯誤、開玩笑、一起學習，能有各自主導的章節。他們早已有感情安全感，遊戲不設「一個選項令兩人感情歸零」的懲罰。
- 魔法、傷勢、死亡、治療、復活及物資持久化尚待規則化；**不能因劇情方便而忽然無限施法或無代價復活**。

## 8. 故事邏輯鏈（主線必須可追溯）

1. 結界受暮蝕侵蝕 → 研究者以逆刻星鐘回溯世界，暫時推遲災難，卻消耗有限星核。
2. 星鏡向界外傳出不完整片段 → 現實開發者製作 RPG；其文案混有誤解與補完。
3. 同機雙人遊戲與星鏡異常共鳴 → 兩人跨界，誤把同步出現的古石門當作歸途。
4. 生活、商道、旅人與城史提供五段可重讀的線索 → 古石門實測失敗後，兩人自行推理出舊觀星台。
5. 觀星台殘記首次指出星鏡及界外傳訊 → 下一調查方向成立，世界隨即重置。
6. 主角記得、居民忘記 → 第二輪一面追查星鏡，一面驗證時間重複；返家與居民的未來逐漸相連。
7. 找到星鏡並確認最初印記 → 返家具有可行依據；受損結界與輪迴卻阻礙穩定通道。
8. 三錨、研究者與工匠提供修復方案 → 揭露守門人被誤認為魔王，避免誤傷封印。
9. 以證據、協作、同步與風險處理，解決封印與星鐘強制回溯 → 世界能持續前行。
10. 第九十一日後，由專家校準星鏡並以印記建立回程 → 居民擁有明天，兩人返回現實。

## 10. 未定義事項與後續設計檢查

### 跨界規則：優先精密設計，不可因劇情需要補完

- 界外印記儲存甚麼、如何辨認原世界／裝置連接、如何經歷回溯仍可確認；定位資料與穩定通道必須分開驗證。
- 最初跨界事故為何發生；雙人同機、遊戲石門場景與星鏡共鳴各自是必要條件還是同時事件。
- 現實流逝多久、回程時間與位置、肉身／角色外貌如何對應；不得暗中確立同一秒返家或固定時間倍率。
- 星鏡本體所在、觀星台殘記指向的下一調查地點、校準程序、供能需求、安全條件與是否有額外代價。
- 第九十一日後能否聯絡／再訪；未定前不預設永久失聯或可隨時穿越。

### 其他待定

世界正式名稱、具體地圖與曆法、其餘角色正式姓名、王國制度、職業與技能成本、戰敗／治療／復活、玩家回溯權限、UI 的敘事地位、緊急重置的觸發條件、背包與位置跨輪處置、殘響精度、多結局數目。原有暫定規則不因本次主線更新自動變成確立。

**寫作／實作前檢查**：每章推進哪個眼前目標與歸途目標？角色此時知道甚麼、只是推測甚麼？線索在何處得到、當時有甚麼合理解釋、何時被重讀？不做可選支線仍能否走通？NPC 的共同經歷與實物是否真的跨輪保留？兩位主角是否仍像自己？未定設定使用 `TBD`，不得默默寫成世界真相。
