# 03｜專有名詞辭典與用語規範

> 本文件供創作、對話、遊戲 UI、資料檔及 Codex 使用。名詞有穩定的 **ID**，以免將來改中文名稱時破壞程式資料。名詞狀態：**【確立】**＝方向或人物關係已確認；**【暫定】**＝目前工作名稱／設定；**【待定】**＝不可擅自當成事實。
>
> **劇透分級**：`公開`＝玩家在序章／遊戲宣傳可見；`初期`＝穿越後逐漸可見；`中期`＝首次重置前後才揭露；`後期`＝接近真相或終局才明示；`作者用`＝遊戲內未必使用的創作術語。

### 唯一固定的男女主角彼此稱呼【確立】

- **西對山田**：「健太郎」。**山田對西**：「奈津美」。
- 第三人稱**旁白**可使用「西」「山田」。對話中不得習慣性互喊姓氏。
- 不要因地點或立繪改變而將人物人格重置；勇者與魔女就是兩人本人。
- 真實世界髮型：**山田棕色短碎髮、西黑色短鮑伯頭**；遊戲世界造型：**山田金色短碎髮、西長直黑髮**。服裝、髮型是外觀切換，不是換人。

## III. 災難、時間與記憶

| ID | 名稱 | 定義 | 關鍵限制 | 狀態 | 分級 |
|---|---|---|---|---|---|
| `PHEN_ECLIPSE` | **暮蝕** | 侵蝕古代結界的危機，影響星光、魔力、魔物與地區穩定。 | 是危機／現象，不應直接等同「魔王本人」。 | 暫定 | 公開 |
| `SYS_BARRIER` | **古代結界** | 維持艾斯特拉魔法環境與封印裂縫的核心防護。 | 星鐘不能永久修復它。 | 暫定 | 中期 |
| `SYS_STAR_CORE` | **星核／星核能量** | 支撐結界、被逆刻星鐘消耗的有限能量來源。 | 不等於三座星錨，也不是方便無限補充的道具。 | 暫定 | 中期 |
| `SYS_REWIND_CLOCK` | **逆刻星鐘** | 把世界回到某固定時間起點、延緩災難的古代裝置。 | 重置是**拖延**而非**治癒**；每次需要代價。 | 暫定 | 中期 |
| `TIME_CYCLE` | **九十日輪迴** | 暫定每次從原初日走到暮蝕臨界的九十日循環。 | 不是現實世界日曆；特殊提早觸發規則待定。 | 暫定 | 中期 |
| `TIME_DAY_ZERO` | **原初日** | 每輪的起點；大部分世界狀態恢復到這一天。 | 「第 1 日」與「原初日」是否同一天，程式資料統一設為輪迴第 1 日，避免 0/1 混用。 | 暫定 | 中期 |
| `TIME_DAY_91` | **第九十一日** | 成功停止重置後，世界第一次抵達原本到不了的明天。 | 是主題性稱呼，不代表故事必然只經歷一個完整輪迴。 | 暫定 | 後期 |
| `PHEN_ECHO` | **殘響** | 某些地點／物件殘留跨輪碎片，造成夢、筆記、似曾相識等異常。 | 不等於 NPC 普遍恢復完整記憶；必須有媒介。 | 暫定 | 中期 |
| `STATE_RESET` | **世界重置／回溯** | 星鐘啟動後的結果：回到原初日，多數 NPC 失去上一輪記憶及經歷。 | 主角記得≠NPC 記得；裝備處理待定。 | 暫定 | 中期 |

### 最容易混淆的四個概念

**暮蝕**是威脅；**古代結界**負責阻隔威脅；**逆刻星鐘**是以耗能回溯來延緩毀滅；**星錨**則是嘗試真正恢復結界的穩定設施。四者功能不能互換。

### 三座星錨修復次序（第一版主線施工順序）

`鑄火 → 森之 → 潮汐 → 終夜封印 → 星鐘最後處置`

這是**章節設計順序**，不代表世界規則強制只能這樣走。若將來需要真正的開放探索，可在保留因果要求的前提下調整。

## V. 官方任務敘事與隱藏真相對照

| 玩家／居民初期相信 | 作者掌握的暫定真相 | 預定揭露 |
|---|---|---|
| 世界受到魔王威脅 | 暮蝕是真正危機；守門人被誤認為魔王 | 第 9–10 章 |
| 勇者打倒魔王就能迎接黎明 | 直接殺死守門人或令封印崩解，可能觸發又一次重置 | 第 10 章 |
| 古老的英雄傳說是一條連續歷史 | 記錄可能拼接多個已重置的九十日 | 第 5–9 章 |
| NPC 只是遊戲人物 | 艾斯特拉獨立存在，居民有真正的生活與命運 | 第 2 章起逐步呈現 |
| 完成任務的世界會一直存在 | 若不修復結界，重置將抹去居民的進展 | 第 5 章 |
| 重置只是在「重新開始」 | 逆刻星鐘持續耗盡有限星核能量 | 第 6–9 章 |
| 現實遊戲設計者創作了整個世界 | 遊戲可能只是接收了界外星鏡外洩的歷史碎片 | 第 9–11 章 |

**劇透實作建議**：角色說話、NPC 筆記、任務 UI 可以「相信錯誤的傳說」，但遊戲旁白不得提前當作真理宣布作者層的秘密。設定檔可把 `public_lore` 和 `hidden_truth` 分開處理。

## VI. 劇情製作與程式術語

| ID | 用語 | 製作用途 | 原則 |
|---|---|---|---|
| `NARR_POV` | **視角／POV** | 同一事件以不同人物的知覺、想法呈現；序章有西、山田雙視角。 | 不能讓角色知道未曾親眼見到或被告知的情報。 |
| `NARR_SCENE` | **場景／Scene** | 最小可播放劇情段落，有背景、角色立繪、台詞、事件。 | 劇情與 UI 程式分離。 |
| `NARR_BRANCH` | **分支／Branch** | 玩家選擇造成不同台詞、探索順序、支線後果。 | 不因單選項就改寫情侶已確立的性格。 |
| `STATE_FLAG` | **劇情旗標／Flag** | 記錄玩家得知線索、NPC 支線進度或觸發事件。 | 標記已知事實，不把未定設定寫死。 |
| `STATE_CYCLE` | **輪迴序號／Cycle** | 表示第幾輪世界，與當輪天數分開。 | 例如第 2 輪第 3 日，不可直接寫「第 183 日」。 |
| `STATE_DAY` | **輪迴日／World Day** | 每一輪內的日期，預設用 1–90。 | 時間線可能調整，但重置前後應一致。 |
| `STATE_AWARE` | **NPC 認知狀態** | NPC 是普通居民、接觸殘響或完整知情者。 | 不以同一個 boolean 代表所有記憶層次。 |
| `VIS_PORTRAIT` | **人物立繪** | 現實與遊戲版本各自一套，後續可增加表情與姿勢。 | 現實與 RPG 髮型不可互換。 |
| `VIS_CG` | **劇情 CG** | 重要情感、環境、轉折事件的獨立構圖插畫。 | 與立繪、背景圖分開管理。 |
| `NARR_BACKLOG` | **對話回顧** | 玩家重新閱讀先前已出現的文字。 | 應支援繁體中文長段敘述。 |
| `GAME_SAVE` | **存讀檔** | 記錄章節位置、分支旗標、輪迴進度及完成支線。 | 不得把已重置的 NPC 當作仍有上一輪記憶。 |

## VII. 用字一致性與禁忌

### 推薦寫法

- **「奈津美」「健太郎」**：只要角色面對彼此說話就使用名；旁白可用「西」「山田」。
- **「自動車專門學校」**：不可誤寫成山田也讀大學；他與西的學校不同。
- **「魔女」與「勇者」**：在劇情中是職業；沒有自動強制的男強女弱關係。
- **「星鐘重置」**：表示重新開始的現象；**「星錨修復」**：表示嘗試解除必須重置的根本原因。
- **「殘響」**：片段／媒介；不要與完整跨輪記憶混同。

### 應避免的錯誤

1. 「健太郎每次都衝動到忽略奈津美」——不符合已確認的戀愛人格；行動力強也能尊重對方。
2. 「奈津美一遇到陌生人就結巴害羞」——大學階段的她已能自然社交。
3. 「兩人穿越後要重新建立對彼此的信任」——他們本來便信任對方，成長焦點是冒險與新世界。
4. 「NPC 突然記得全部輪迴，只因感動」——若有特殊記憶，須依殘響或明示的魔法規則。
5. 「魔王被打倒，暮蝕自然就消失」——與守門人反轉及結界機制衝突。
6. 「星核＝星錨＝星鏡」——三個是不同概念：**能源／穩定設施／跨世界連接**。
7. 「世界在第 90 日必定毀滅但主角沒有時間限制」——每個修復任務須與輪迴日數和緊迫性相容。
8. 「遊戲設計師知道所有真相」——目前提案是他誤以為片段來自夢與靈感，並不知世界確實存在。

## VIII. 名詞變更流程（供後續修改）

更名時優先保持 `ID` 不變，並同步更新三份文件、遊戲顯示名稱、角色台詞與素材索引。例如將「艾斯特拉」改為另一個世界名，仍可保留 `WORLD_ESTELLA` 作內部穩定 key，或以有紀錄的 migration 改 key；切勿只更改其中一份文件造成同義多名。

若新增機制，請先寫入世界觀的**因果與限制**，再加入本詞典的**定義與劇透分級**，最後更新章節大綱的**首次登場與可玩後果**。若作者未確認，狀態維持 **【待定】／【暫定】**。

> **一句話辨識核心謎團**：暮蝕傷害結界；星鐘用輪迴拖延；殘響透露被抹去的時間；三座星錨使真正修復成為可能；守門人撐住最後封印；守鐘人害怕賭上所有人的明天；界外來者把不同輪迴的線索連接起來。
