# 踩地圖｜玩法第一階段

2026-11-05。本階段先驗證可玩循環，所有任務事件、情報、路線名稱、初始金錢與門檻均為**佔位／測試值**，不能當成新增正式劇情。

## 試玩方法

開始畫面 → **踩地圖 · 玩法試玩**。首次可選「帶我試一次」或跳過。實際操作教程帶領選角色、踩廣場、接委託、去旅舍、完成操作及領取報酬。每步標示當前操作目標；完成／跳過均保存。

試玩進度存在獨立 `yamada-nishi:world-preview`，不寫入故事手動／自動存檔。可用「重新試玩」重置這份測試進度。正式故事最後讀完第二章後，按「進入村莊」才解鎖正式生活進度；之後「開始故事」按自動存檔的 mode 返回地圖，若在故事途中則返回故事。

## 已確立玩法

- 三個時段：早、午、晚。移動、查看資料、接任務、付款、換控制角色均不耗時。
- **只有村中廣場委託處可接工作任務**。接好後看目的地，再去當地進行。其他地點可調查／取得情報，沒有接任務按鈕。任務頁只記錄已接／已完成工作並提供前往地點。
- 控制山田或西。正式開始活動時，另一人按可重現亂數安排同行／工作／練習。雙人任務強制同行。無獨立約會按鈕，日後相處情節由任務事件承載。
- 完成或放棄活動消耗一時段；重試／中途關閉不再次扣時。活動 pending 一經開始即保存，不能用換角色／讀檔重抽。結算以 day:period 作 receipt，防重複領取。
- 委託操作暫用一個三次命中的簡單指針挑戰，目標每輪變動。技能差異、困難參數、NPC 事件、正式調查遊戲後續才加。
- 夜間活動完成或晚上在旅舍睡覺，推進翌日並記住宿費；金額不足先記欠款，不觸發破產或劇情懲罰。上午／下午可以主動等待，不產生同伴收入。
- 背包記錄測試道具，技能頁分角色累積熟練度，暫無裝備／使用效果或技能加成。
- 收集兩項佔位情報可開一條局部測試路線。第三章準備另外檢查準備金、住宿付款和無欠款、必要情報；達標只顯示第三章佔位，不自動扣錢或跳入不存在的正文。

## 資料與程式

- `src/content/world.json`：地點、相對座標、唯一委託處、任務、可用時段、報酬、道具與測試金額。
- `src/world/world-engine.js`：無 DOM 的規則與保存狀態，純資料驅動，seed／pending／receipts／tutorial 都隨世界保存。
- `src/world/village-ui.js`、`village.css`：地圖、地點面板、任務紀錄、背包、熟練度、準備清單、可跳過操作教程、簡單挑戰。
- `src/main.js`：VN／地圖路由與第二章入口。保留現有 NovelEngine，新增可選 `state.world`、`state.mode`。
- `src/engine/validate.js`：驗證世界資料與存檔；舊版 v1 故事存檔沒有 world 仍可讀取。未更名或清除原存檔 key。新的世界欄位不保證舊程式能理解，應以新版本讀取。
- `tests/world.test.js`：時間、角色、報酬、欠款、跨日、同伴、任務、地圖門檻、教程及 v1 存檔相容性。

世界狀態與讀過的正文分開保存，world 模式仍保留上一個 VN 段落。從地圖返回故事進行回顧不清除世界，第二章入口已解鎖時沿用既有世界而不再發初始金幣。

## 地圖美術

以既有村路與旅舍內景為風格參考，透過 **built-in image_gen** 生成斜俯瞰圖；是位置試作，沒有新增正式設施。原 PNG：`../../../01bg/bg-estrala-village-aerial-prototype.png`；runtime WebP：`../../public/assets/backgrounds/bg-estrala-village-aerial-prototype.webp`。完整提示詞見 `map-prompt.json`。按鈕與圖片分離，以 0–100 百分比座標定位；圖片換掉後可只改 JSON 座標。

下午／晚上暫以同一張圖調色，不代表已有獨立夜景。窄螢幕橫向滑動地圖，亦提供地點清單；面板移到地圖下方。地圖與任務均可鍵盤操作。

## 下一階段

先由作者試每日時間／收入／支出循環，再定正式數值與事件位置。之後擴充分角色玩法、技能、難度與變化，才補 NPC 對話、任務內相處情節、正式情報與第三章目的地。不可把暫時的「整理物件」「協力搬運」「情報 A/B」當作已確認正式情節。

限制：本機瀏覽器儲存、沒有跨裝置同步；新指針挑戰暫不保存每一擊，重開會重新試同一活動，原同伴／時段保持不變；NPC 目前只標出人物，沒有虛構對話；不宣稱已完成複雜養成或第三章。
