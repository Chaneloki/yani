# Artwork input

此處僅接收作者提供的圖片，未附帶第三方角色素材。

建議路徑：
- characters/kentaro/real/{neutral,smile}.webp
- characters/kentaro/hero/{neutral,smile}.webp
- characters/natsumi/real/{neutral,smile}.webp
- characters/natsumi/witch/{neutral,smile}.webp
- backgrounds/<stable-name>.webp
- cg/<stable-name>.webp

使用 src/content 的表格登記相對 URL：`./assets/...`。`null` 為刻意佔位，無需建立空圖片。
